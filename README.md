# 🏥 Smart IV Bag Monitoring & Alert System

An IoT-based healthcare monitoring system designed to continuously track IV fluid levels and generate alerts before the saline/medicine bag becomes empty.

This project helps reduce manual monitoring effort in hospitals and improves patient safety through real-time monitoring and notifications.

---

## 🚀 Features

- Real-time IV fluid level monitoring
- Automatic low-level alert system
- IoT-based remote monitoring
- Reduces manual checking by medical staff
- Improves patient safety
- Wireless data transmission
- Smart healthcare application

## ⚙️ Working Principle

The system continuously monitors the fluid level inside the IV bag using sensors.

When the liquid level falls below a predefined threshold, the microcontroller triggers an alert notification using buzzer and IoT communication.

The monitoring data can also be transmitted wirelessly for remote observation by healthcare staff.
